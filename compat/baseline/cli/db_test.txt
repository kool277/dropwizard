usage: java -jar dropwizard-example-VERSION.jar
       db test [-h] [--migrations MIGRATIONS-FILE]
       [--catalog CATALOG] [--schema SCHEMA]
       [--analytics-enabled ANALYTICS-ENABLED] [-i CONTEXTS] [file]

Apply and rollback pending change sets.

positional arguments:
  file                   application configuration file

named arguments:
  -h, --help             show this help message and exit
  --migrations MIGRATIONS-FILE
                         the file containing  the  Liquibase migrations for
                         the application
  --catalog CATALOG      Specify  the   database   catalog   (use  database
                         default if omitted)
  --schema SCHEMA        Specify the database schema  (use database default
                         if omitted)
  --analytics-enabled ANALYTICS-ENABLED
                         This turns on analytics  gathering for that single
                         occurrence of a command.
  -i CONTEXTS, --include CONTEXTS
                         include change sets from the given context
exit=0
